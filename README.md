# Agent Durbar worlds

World packs that [Agent Durbar](https://github.com/three-feathers/agent-durbar) can download on demand. A pack holds art and data only, never code.

The rules, the pack format and the review process live in the app's repository: its `AGENTS.md`, spec 102 and `docs/world-design.md`. Worlds that ship inside the app stay in that repository.

Nothing is published here yet.
